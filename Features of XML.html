Features of XML The most common features of XML are as follows 1. XML specifies data description: The focus of XML is on description of data, not its presentation 2. XML is a structured format: We can define exactly how the data is to be arranges, organised and expressed with in the file XML is a user defines langauge, that it always used to create your own tags 3. XML can easily describe hierarchical data and the relationships between the data: It provides the relationships between root element and its child element. The hirerarichal structure is suitable for most types of documents 4. XML is platform independent: XML can be run on all platforms. It enables you to execute xml based applications on any operating system such as windows, UNIX, etc. 5. XML has user defined and extensible tags: XML tags are not pre defined, it means it supports user defined tags which user can define as per the requirement 6. XML is a global Format: There is only one way to express a number in an xml file and only one way to express a date 7. XML is a meta langauge: It can be used to create new langauges. There are several languages derived from xml such as math ML, which is a markup language used for the representation of mathematical formulae and scientific data Similarly, wireless markup langauge(WML) which is used for web applications that can be accessed by cellular phone is also derived from XML Some other languages a.
